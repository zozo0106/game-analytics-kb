## 每个项目的统一结构

```
0X-<项目名>/
├── README.md          # 业务问题 → 方法 → 结论（30 秒能看懂）
├── data/
│   ├── generate_data.py   # 合成数据生成器（一键复现，不依赖外部下载）
│   └── *.csv              # 生成的数据（可提交，文件小）
├── sql/               # 口径与特征提取（SQL 是一等公民）
├── python/            # EDA / 建模 / 评估
├── assets/            # 图表输出
└── report.md          # 带真实数字的分析报告
```

## 复现约定

```bash
cd 0X-<项目名>
pip install -r requirements.txt
python data/generate_data.py        # 1. 生成合成数据
python python/build_features.py     # 2. SQL 提特征/指标
python python/01_*.py               # 3. 第一步分析（EDA / 实验体检）
python python/02_*.py               # 4. 主分析（建模 / 检验）
```

- 数据全部为**合成数据**（无真实/敏感数据），seed 固定，结果可复现
- 生成物（CSV/图/指标）由 `.gitignore` 排除，仓库只留脚本 —— clone 后跑一遍即可重建
- 依赖：`pandas numpy scikit-learn matplotlib`（见各项目 requirements.txt）
- 方法论涉及的事实性内容附「参考来源」，无权威来源的数值标注为"经验区间/示意"
