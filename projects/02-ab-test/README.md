# 02 · A/B 测试分析框架（规划中）

> 目标：做一个**能跑**的 A/B 实验分析框架 —— 从实验设计到显著性检验到结论输出，全流程模板化。

## 计划内容

- [ ] 合成实验数据生成器（对照组 / 实验组，含真实效应与噪音）
- [ ] 实验设计：样本量计算（power analysis）、分流校验（SRM 检查）
- [ ] 显著性检验：两比例 z 检验、t 检验、置信区间
- [ ] 常见坑的可视化：辛普森悖论、多重比较、新奇效应
- [ ] 结论模板：一键输出"实验报告"（提升显著？可上线？）

## 面试考点映射

- 实验设计能力（分流、样本量、指标选择）
- 统计功底（假设检验、置信区间、p 值 vs 实际显著性）
- 业务判断（统计显著 ≠ 业务显著）
