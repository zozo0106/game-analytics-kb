# 留存体系：D1/D7/D30、Cohort 与留存曲线形态解读

> 一句话摘要：留存是游戏唯一的"真话"——买量决定谁进来，留存决定谁能活下去。这篇文章讲清三件事：留存怎么定义、Cohort 怎么看、曲线形态怎么读。

> ✅ 核对状态：定义与口径已对照 GameAnalytics 公开文档与学术文献（Kaplan-Meier 生存分析 / Fader-Hardie 非合约客户留存建模）核对；基准区间为**行业经验参考区间**，随品类与年份浮动。

## 背景

游戏行业有句实话：**买量是买"进来的人"，留存是留"留下的人"**。流水可以靠活动脉冲冲高，DAU 可以靠买量堆出来，但**留存曲线骗不了人**——它直接反映产品本身的吸引力。

留存分析看起来简单（"第 7 天还剩多少人"），但真正踩坑的地方有三个：**口径没对齐**、**只看单点不看曲线**、**只看整体不看分层**。

## 框架：留存的三层结构

**第一层 · 时间维度（看什么周期）**

| 指标 | 回答的问题 | 失守意味着 |
|:---|:---|:---|
| D1 留存 | 第一印象 / 新手体验 | 新手引导、首日节奏、技术稳定性有问题 |
| D3–D7 留存 | 一周游戏循环是否成立 | 缺少周常目标、中期内容断层 |
| D14/D30 留存 | 长期内容供给与养成深度 | 内容消耗过快、社交/养成系统不够深 |

**第二层 · 口径（最容易出事的地方）**

留存有两种主流口径，**差异巨大，必须写死**：

- **N-day 留存（固定日）**：某日新增用户中，**恰好第 N 天**活跃的比例。行业默认口径，数值较低。
- **Unbounded / rolling 留存（不固定日）**：某日新增用户中，**第 N 天及之后**仍活跃过的比例。数值明显更高。

> 同一个产品，说"D7 留存 20%"还是"35%"可能只是口径不同。**报表里不写口径的留存数字，一律不可比。**

**第三层 · Cohort（按批次看）**

留存必须按**新增批次**分群（按日/周/月），才能区分"产品变好了"还是"最近买量变差了"。Cohort 留存表（三角表）是行业标准视图：横轴是生命周期天数，纵轴是新增批次。

## 方法（怎么读、怎么用）

**1. 把留存曲线当生存曲线看**
留存曲线本质是**生存函数 S(t)**，流失率对应**风险率（hazard）**。生存分析（如 Kaplan-Meier 估计）能正确处理"观测期未结束"的用户（右删失），避免用"还没到第 30 天"的用户去算 D30 留存——这是手工算留存最常见的错误（Fader & Hardie 的客户基数模型也是同一思路）。

**2. 看形态，不只看单点**

- **早期陡降**：D1→D7 断崖 → 新手漏斗问题（引导太长、首充逼氪、崩溃率）
- **中期衰减**：D7→D30 平滑下滑 → 内容消耗速度问题
- **后期平台期**：曲线尾部走平 → **平台的绝对高度就是产品的核心用户盘**，决定 LTV 天花板

**3. 找拐点，而不是找借口**
把曲线做**双对数坐标**，看它在哪一天开始偏离幂律（"开口"）：拐点往往对应一个具体的产品事件（卡关、缺社交目标、内容见底）。

**4. 必须分层**
整体留存涨了，可能只是买量结构变了。渠道、机型、地域、是否付费、是否社交，都要拆开看——否则极易撞上辛普森悖论（参见 [A/B 测试常见坑](../04-experimentation/pitfalls.md)）。

## 案例（脱敏，数值为合成示意）

某 SLG 手游改版新手引导，整体 D1 留存从 38% 抬到 41%，团队打算全量上线。数据侧复核：

1. **分渠道拆解**：自然量 D1 提升 **+5pp**，但买量用户反而 **−1pp**（新引导更长，买量用户更没耐心）→ 整体提升主要是"自然量占比提高"造成的假象
2. **曲线定位**：D1→D7 曲线在**第 3 天**出现明显陡降，用 hazard 一看，第 3 天风险峰值对应"关卡 5 失败率 62%"
3. **干预**：下调关卡 5 难度后，D7 留存从 19% 抬到 23%，且**平台期从 12% 抬到 15%**（说明不只是首日好看，core 盘真的变大了）

结论：留存分析的价值不在"看数字涨没涨"，而在**定位到"哪一天、哪个人群、哪一步"掉链子**。

## 要点速记

- [ ] 留存先对齐口径：**N-day 还是 unbounded**，报表必须写死
- [ ] 按**新增批次（Cohort）**看，别把不同质量的新用户混在一起
- [ ] 留存曲线 = 生存函数，处理"观测期未结束"要用生存分析而非简单除法
- [ ] 看形态：早期陡降=新手问题，中期衰减=内容问题，**平台期高度=产品天花板**
- [ ] 定位到**具体拐点/具体人群**才算分析完成，否则只是报数
- [ ] 分层必做：整体留存变化可能只是买量结构变化（辛普森）
