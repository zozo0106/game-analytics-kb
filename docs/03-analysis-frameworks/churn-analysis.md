# 流失分析框架：从定义到召回的全闭环

> 一句话摘要：流失分析的标准四步法——量化流失 → 定位流失 → 归因流失 → 干预召回，附每步的方法与常见坑。

## 背景

流失分析是游戏数据分析出现频率最高的专项，也是"分析能直接变现"的典型场景：**每挽回一个流失用户，省下的是一份买量成本**（挽回老用户成本通常远低于获取新用户）。但多数流失分析做得浅——停在"算了个流失率"就结束了。完整的流失分析是一个从定义到干预的闭环。

## 第一步：定义流失（口径先行）

| 问题 | 建议口径 | 说明 |
|:---|:---|:---|
| 多久不登录算流失？ | 7/14/30 日未登录，按品类定 | 休闲游戏 7 日即可算流失；SLG/MMO 可放宽到 30 日 |
| 分析谁？ | **新增用户流失** 与 **存量活跃流失** 分开 | 两者成因完全不同：前者是新手体验问题，后者是内容消耗完/版本问题 |
| 是"永久流失"吗？ | 区分"暂时不活跃"与"真流失" | 用历史回归数据看：流失用户中 X% 会在 Y 日内回归，定义要留缓冲 |
| 按什么维度去重？ | 与全局口径一致（账号/设备） | 口径不一致，后续所有分析全偏 |

## 第二步：量化与定位（流失发生在哪）

1. **流失率总览**：分新增批次看流失曲线（Cohort），找到"流失加速拐点"
2. **按生命周期阶段拆**：新手期（D0-D1）/ 成长期（D1-D7）/ 稳定期（D7-D30）/ 长线期（30+），各阶段流失原因完全不同
3. **定位关键流失点**：
   - 新手流失专项：教程流失节点、前 N 关通过率、新手引导跳出点
   - 中期流失：内容消耗速度（是否"玩穿"了）、版本间隔空窗
   - 长线流失：社交关系断裂、公会/战队解散、赛季结算节点
4. **量化流失代价**：流失用户数 × 人均 LTV = 流失造成的收入损失——这是向业务方要资源做召回的"账本"

## 第三步：归因（为什么流失）—— 流失前行为特征对比

核心方法：**拿流失用户 vs 同期留存用户做特征对比**，找差异显著的先行指标。

| 特征维度 | 典型发现 | 业务含义 |
|:---|:---|:---|
| 活跃频次骤降 | 流失前 7 天登录次数从 X 降到 Y | 有"预流失"信号期，可提前干预 |
| 玩法参与深度 | 流失用户主玩法参与率显著低 | 核心玩法没建立 habit loop |
| 社交关系 | 流失用户无好友/公会/组队行为 | 社交绑定是留存最强护城河之一 |
| 进度与数值 | 卡关、卡资源、付费墙前流失 | 难度曲线/数值节奏问题 |
| 付费行为 | 首充后即流失（"买断体验"） | 付费内容与后续体验不匹配 |
| 版本节点 | 集中在某版本更新后流失 | 版本改动失误（如平衡性、负优化） |

补充证据源：**客服工单/舆情/商店差评**（定性验证定量假设）+ **竞品对照**（同一批用户去玩了什么）。

> 进阶：特征足够后，可用逻辑回归/树模型做**流失风险打分**，对高风险用户做前置干预——这是"分析→模型→运营动作"的完整链路，简历和面试都极加分。

## 第四步：干预与召回（闭环）

**召回不是群发推送，是分层运营：**

| 流失类型 | 召回钩子 | 渠道 | 效果衡量 |
|:---|:---|:---|:---|
| 新手期流失 | 新手礼包补发、引导优化后邀请回归 | 推送/短信 | 召回率、回归后次留 |
| 内容型流失 | 新版本/新玩法上线节点召回 | 推送 + 商店更新 | 版本召回峰值 |
| 社交型流失 | "你的队友还在等你"、回归礼包 | 社交/推送 | 回归率、社交重建率 |
| 大 R 流失 | 专属客服 1v1、定制回归方案 | 人工 | 回归率、回归后付费 |

**召回效果闭环指标**：召回触达率 → 回归率 → 回归后 7 日留存 → 召回 ROI（召回收入 ÷ 召回成本，与买量 ROI 同口径对比）。

## 案例（脱敏复盘）

某卡牌项目发现 30 日留存低于竞品 8pp → ①量化：流失集中在 D7-D14，损失约月流水 12% → ②定位：中期玩家"主线推完、无事可做" → ③归因：对比流失与留存用户，差异最大特征是"是否加入公会"与"是否参与限时活动" → ④干预：上线"赛季制 + 公会战"版本，并对 D7 预流失用户（活跃频次骤降信号）提前推送新玩法预告 → 结果：30 日留存提升 5pp，召回 ROI 为买量 ROI 的 2.3 倍。

## 要点速记

- [ ] 流失分析第一步永远是定口径：多久算流失、分析新增还是存量、是否区分暂时性不活跃
- [ ] 新手流失看体验，中期流失看内容，长线流失看社交——不同阶段病因不同，别用一个框架套到底
- [ ] 流失用户与留存用户的**行为特征对比**是归因的核心武器，先找差异再谈原因
- [ ] 多数用户流失前有"预流失信号期"（活跃骤降），抓得住就能前置干预
- [ ] 召回要分层设计钩子，衡量标准是召回 ROI，而不是"发了多少推送"
- [ ] 流失分析的价值主张：挽回老用户的成本 << 买新用户，这就是分析的 ROI
