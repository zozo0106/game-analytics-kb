# 活动效果评估：无法做 A/B 时怎么算清"增量"

> 一句话摘要：节日活动、充值返利、拉新裂变往往全局上线、无法随机分流，这篇文章给出"没有对照也能估因果"的四类方法，并讲清最容易翻车的点——把"总量上涨"当成"活动增量"。

## 背景

活动是游戏运营最常用的抓手，但"活动上线后流水涨了 18%"这句话**几乎不能证明活动有效**。涨的原因可能是：大盘季节性（春节人人充值）、版本更新叠加、买量节奏变化，以及最关键的一点——**参与活动的用户本来就更活跃、更愿付费**（自选择偏差，self-selection）。

跟 [A/B 测试](../04-experimentation/ab-test-design.md) 不同，活动通常**全局上线**：想给一半用户看、一半不看，运营上往往做不到（社交传播、全服榜单、氛围感都会穿帮）。没有随机化，就没有现成的对照组——这就是活动效果评估的全部难点：**如何人为构造一个"没做活动的反事实"**。

## 框架：活动效果评估五步

**第一步 · 锁一个主目标**
一次活动只认一个北极星：拉新 / 活跃 / 付费 / 召回。目标不同，口径与窗口完全不同（付费看活动期+回落期，召回看回归后留存）。

**第二步 · 构造对照组（核心）**
按可信度从低到高四选一：

| 方法 | 做法 | 适用 / 局限 |
|:---|:---|:---|
| 前后对比 | 活动期 vs 活动前 | 最简单，但混入季节与趋势，只能做粗估 |
| 同期人群对照 | 参与 vs 同期未参与用户 | 直观，但**自选择偏差**严重（参与的本就活跃） |
| **双重差分（DID）** | (处理组活动后−活动前) − (对照组活动后−活动前) | 扣掉共同趋势；需假设两组趋势平行 |
| **倾向得分匹配（PSM）** | 按参与概率把参与/未参与用户配对 | 缓解自选择；只能平衡"可观测"特征 |
| **合成控制** | 用多个未受活动影响的单元加权，拼出"没做活动的对照" | 适合"整服/整区全量上线"场景 |

**第三步 · 隔离混杂**
剔除季节性（用**同比**而非环比）、剔除版本（对照组取同期）、剔除买量结构变化（只看自然量或按来源分层）。

**第四步 · 算"增量"而不是"总量"（最容易出错）**
总流水上涨 ≠ 活动带来这么多。要警惕**提前消费（pull-forward / 挤占效应）**：返利让用户把本来下个月要充的钱提前充了，活动一结束就回落。

> **净增量 = 活动期超额收益 − 活动后回落**。所以口径必须对齐"活动期 + 等长滞后窗"，只看活动期会系统性高估。

**第五步 · 算 ROI 并给建议**
活动 ROI = 增量收入 ÷ 活动成本（奖励/折扣成本 + 人力），**与买量 ROI 同口径**，这样才能回答"这笔钱投活动还是投买量更划算"。

## 方法（落地要点）

- **前置漏斗**：触达率 → 参与率 → 完成率 → 转化率，先确认活动"跑起来了"再看收益
- **DID 公式**：净效应 =（处理组后−处理组前）−（对照组后−对照组前）
- **对付自选择**：优先用**触达作为随机单元**（intention-to-treat，谁被推了活动谁进处理组），或对参与用户做 PSM
- **回归/断点**：活动带门槛（如满 100 元返 20）时，可用**断点回归**看在门槛两侧的行为跳变
- **时间序列反事实**：完全没有可用对照时，用**贝叶斯结构时间序列**（CausalImpact 一类）拟合"若无活动"的预测区间（见参考来源 Brodersen et al.）
- **护栏指标**：活动后 D7 留存、付费率、ARPU 是否被透支——别用长期价值换短期流水

## 案例（脱敏，数值为合成示意）

某充值返利活动，活动期流水环比 **+18%**，运营初判"大成功"。数据侧复核：

1. **DID**：以同期未触达的同层用户为对照，扣除大盘上涨后，净增量降到 **+6%**
2. **滞后窗**：活动结束后 2 周流水回落 **−4%** → 净增量进一步收到 **+2%**（说明主要是提前消费）
3. **PSM**：对参与用户做匹配后，净增量仅剩 **+1.3%**
4. **ROI**：按 +1.3% 增量与返利成本算，**低于同期买量 ROI**

结论：活动主要把"本来要发生的付费"提前了，真实增量很薄 → 建议把"充值返利"改成"限时赠品/皮肤"（不直接替代现金付费）。**同一个活动，口径不同，结论从"大卖"翻成"不划算"。**

## 要点速记

- [ ] 活动全局上线、无法随机 → 不能用标准 A/B，必须人为构造反事实
- [ ] 参与活动的用户本就更活跃/更付费，**自选择偏差**是头号陷阱
- [ ] 四类对照按可信度递进：前后对比 → 同期人群 → DID → PSM/合成控制
- [ ] 算**增量**不是总量：警惕提前消费，口径要覆盖"活动期 + 回落期"
- [ ] 活动 ROI 要和**买量 ROI 同口径**对比，才能回答"钱该投哪"
- [ ] 别用长期价值换短期流水，盯住活动后留存/付费率等护栏指标
